RENEGADE AIR WEBSITE
=====================

This package is a self-contained front-end recreation based on the screenshots supplied and the publicly accessible Renegade Air website reference.

FILES
-----
index.html   Main website
style.css    Responsive styling
app.js       Search, dropdowns, booking flow, seat selection, ticket generation, WhatsApp sharing and destination modal

FEATURES
--------
- Home page and hero search
- Roundtrip / One Way / Multi-City UI
- From/To airport dropdowns
- Passenger dropdown matching supplied options
- Popular Routes with destination cards
- Destination Explore modal
- Wild Kenya gallery with controls
- Renegade Difference (6 features)
- About section
- Footer
- Passenger information form with validation
- Seat selection with taken/available/exit-row states
- Group-booking handling for more than 12 passengers
- Boarding pass/ticket generation
- PNG ticket download
- WhatsApp sharing
- Booking confirmation screen
- Responsive desktop/tablet/mobile layout

NOTE
----
The site is a front-end implementation. Real airline inventory, payment processing, authentication, CRS integration and server-side booking persistence require a backend/API connection.
Images are loaded from public Unsplash URLs, while the site logic and styling are local.
